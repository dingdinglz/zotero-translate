## Responsibility

侧栏和临时分支共用按实际模型判断的思考展示规则，不以 Codex、Pi 或 OpenCode 的 Agent 身份推断模型。GPT 系思考以输入框上方的最新非空进度行展示；其他模型的长思考在对话区独立展示，避免正文被压成短状态。后者生成时底部仅显示 `thinking…`。

模型 ID 去掉 provider 路径后，以 `gpt` 加分隔符、数字或字符串结束匹配 GPT 系；未识别的模型使用独立块，不凭 provider 名推断。新思考条目保存当时的模型 ID，切换模型不改变已知历史的展示方式。旧记录缺失模型时使用当前会话模型；ACP 回放按对应用户轮次匹配模型归属：问题文字、可用的远端消息身份，以及该轮思考条目的数量、顺序和全文必须一致。不能仅按思考文本关联，因为不同模型会返回同一句思考。无法匹配时同样回退，不猜测外部历史使用的模型。

独立块使用原生可折叠控件：当前轮生成时默认展开，用户可自行折叠，流式重绘保留操作；结束、停止或错误后默认折叠，之后可手动展开回看。等待授权与停止中仍属当前轮，但不能把之前轮次的残留 streaming 标记当成新思考。切换论文、Agent、请求或本地会话不继承另一身份的展开状态。

## Boundary

思考内容只作为可选择、可复制的纯文本，不解释为 HTML、工具指令、文件引用、图表或分支入口。仍受现有消息区选区保护：有选区时延迟正文重绘，包括结束自动折叠；状态、停止与授权控件继续更新，清除选区后展示最新状态。

本规则只改变本地呈现及思考条目的模型元数据，不改变思考强度、Agent 权限、网络请求或工作区边界。连接、等待授权与停止提示优先于 thinking 状态。
