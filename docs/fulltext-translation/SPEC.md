## Responsibility

将论文的单个 PDF 附件转换为可检查的 Markdown，用户确认后逐段翻译与校对，保留中文 Markdown 并生成独立中文 PDF 附件。原始 PDF、既有批注及 Agents 会话不变。此模块不承担原版布局复刻、批注迁移或跨语言页码对齐。

用户流程与运行依赖已获批准；本文作为新增持久模块说明，尚待单独审阅。原生打印及实际导入的验证缺口见技术参考，不由自动测试或版本兼容声明推导成功。

## Boundary

任务核心负责确认门控、统一逐页稿、状态和检查点；Markdown 模块负责无损分段、块偏移、保护和安全排版；图片模块负责地址/逐跳策略、图片及缓存校验；网络适配模块负责Gecko手动跳转、DNS预检和匿名有界流；本机桥负责附件身份、文件、图片模块组装与存储、Python 子进程和 Gecko 打印；窗口只绑定打开时的任务，不跟随 Reader 切换。Python 工具仅处理 PDF，拥有 OXR 分块/缓存和本地版面/页面渲染，不持有 DeepSeek 密钥。

Reader 入口从 tabID 精确复核附件，仅支持主窗口 PDF 标签页。全文翻译按钮与中英文原生下拉框作为同一工具组，使用与 Reader 按钮一致的 28px 高度并垂直居中，保留原生选择和键盘语义。没有普通父论文或文库不可写时拒绝，不能猜测另一附件或自动创建父条目。同一任务只保留一个可编辑确认窗口，替换必须先暂停并回收旧服务。

## Consent and network

打开窗口与读取检查点不上传 PDF、不请求模型；当前页、原文全文预览及中文PDF生成前所需的公网 HTTP(S) 图片可经受控后端自动下载并缓存，不逐图弹确认（见图片边界）；生成前补图已获用户授权，不上传论文或新增模型请求。首次明确确认目标地址后，Python 才将 PDF 分块上传至配置的 OXR。默认地址为 Free OXR；只允许 HTTPS 或本机 HTTP，拒绝 URL 中的凭据、查询和片段，不跟随重定向。每块最多 20 页、9.5 MB；单页超限报错，不静默栅格化降质。缓存包含任务 ID、识别内容和版面数据；关闭本地进程不保证取消远端任务，重试提交也可能产生远端重复任务。

另一明确确认才允许向当前 DeepSeek 地址/模型发送待翻译段落，并授权全部通过后自动生成和保存中文附件。共用现有翻译服务配置及 Login Manager 密钥，但全文翻译/校对提示词独立、目标固定为简体中文。当前服务非 DeepSeek 时拒绝，不偷偷改供应商。

只有带 ID 的正文片段和不含原值的结构类别上下文进入模型；图片、代码、公式、引用及链接原值留在本地。不同段落允许有界并发，默认 5 路、范围 1–8；每段内部仍串行执行翻译、独立模型校对、程序校验，任一路最多一个在途模型请求。并发数按当前任务本地保存，运行/回收期间锁定，改变它不改变正文/模型签名或清空检查点；不影响 OXR 解析策略。结构错误每段最多三轮，鉴权/网络/截断类错误不按格式错误重复计费。语义正确性不能由结构校验保证。

任何段落最终失败后立即停止派发新段，已发出的其他段允许完成并保存，然后任务暂停；用户随时暂停/关闭则立即取消全部在途请求。失败段与暂停时已观察到的草稿按段隔离保存，优先恢复这些待处理段；修正入口只切换当前段，不覆盖其他草稿。是否提供修正入口取决于已保存的待处理段，不依赖全局错误文本；进程在失败收尾期间中断，重开也不能隐藏已经保存的失败草稿。只有新协议下完整通过的译文才属于完成检查点；旧标记协议任务不转换草稿或继承已完成结果。

手动修正是默认折叠的高级选项，不是重试前提。失败面板默认提供从已确认原文“重新翻译此段”和“继续未完成段落”；前者只请求选中的未完成段，不复用其失败草稿，不改其他段草稿/成功检查点，只有全文全部通过才组装或进入导出。继续任务复用有效的已保存草稿；无效旧草稿直接重新翻译，不因本地旧稿校验失败白占一轮模型重试。操作有未保存修正时先确认丢弃，取消不清草稿或发请求；确认重译需明确目标、模型及费用，已改原稿/配置仍须重新确认全文。

高级区使用与模型响应相同的 JSON 草稿，只修改 text，保留全部片段 ID 和顺序；编号、换行、公式、代码及链接由本地原稿保管，不要求复制长标记。只在展开且任务空闲时生成当前选中段的有界原文片段 JSON 参照，以纯文本显示，不把受保护资源或所有草稿复制进快照。收起、切换段落或忙碌时清理参照。“保存草稿”经过格式校验后只持久化，不自动请求模型或计入完成；仍须继续模型校对。“放弃未保存修改”只恢复已保存草稿，不写盘或请求模型。保存失败保留编辑，但不会禁用有明确丢弃确认的重译/继续入口，防止无法保存又不能重试。

## Parsing progress

解析阶段按实际上传块展示页码范围、待上传/上传中/已提交等待状态，以及远端返回的排队中、解析中、解析完成；不使用翻译段数或估算百分比代替解析进度。先按既有页数和体积限制规划全部范围，仅保留页码，再逐块重新提取并复核体积，避免为完整列表同时持有全部 PDF 块。提取规则和缓存摘要不变，完成缓存经验证后可直接显示完成，不伪造经历过的远端状态。所有块解析成功后，本地 Markdown/版面整理仍是独立阶段，只有最终结果通过才进入确认页。

进度列表默认展开，解析中及完成后均可用原生 disclosure 展开/收起；刷新保留用户选择与既有行，长列表可滚动。仅点亮实际收到的阶段，未观察阶段保持灰色，暂停/失败保留已观察节点；缓存命中或即时完成不得补造排队、解析经历。普通分块通知按 50 ms 合并，阶段边界、失败与结束立即推送；收起时不刷新隐藏行，展开读取最新快照，避免大量缓存块导致反复全表重绘。顶部显示已完成块数和本次解析耗时，等待远端时耗时持续更新，暂停/失败/结束冻结，窗口关闭回收计时器。异常明确标记且保留已完成块。解析耗时与 UI 状态只在本次服务内存中，不当作持久远端真相；重开不自动提交或轮询解析任务，用户再次确认后通过既有 OXR 缓存重建进度；图片预览的自动加载独立于解析任务。

固定 Python 的 convert 使用逐行、立即 flush 的 JSON 进度帧加一个最终结果；check/preview 仍只有最终 JSON。专用协议描述符绕过第三方库输出抑制，库的原生 stdout/stderr 仍被丢弃。进度仅包含白名单阶段、页数、页码和状态，不带正文、路径、任务 ID 或密钥；桥接拒绝额外键、越界/乱序范围、最终结果后的输出，按 UTF-8 限制单行 64 KiB、convert 总输出 16 MiB，stderr 仍限 64 KiB。任务层复核覆盖范围、顺序与结果页数，暂停或换任务后丢弃迟到事件。

本地原子输出在替换最终目标前同步实际临时文件；渲染器可能关闭并替换初始临时文件，因此仍需重新打开最终临时文件。统一使用不截断的 `r+b`，兼容 Windows `os.fsync()` / `_commit` 对可写描述符的要求；预览 PNG、Markdown/缓存/逐页记录与版面 PDF 均适用。失败仍保留已有目标并清理自有临时文件，不跳过同步。缓存扫描使用 `os.stat(entry.path, follow_symlinks=False)` 获取完整硬链接数，避免 Windows `DirEntry.stat()` 的 `st_nlink=0` 误报；常规文件、硬链接数等于 1、大小及命名限制继续执行，临时文件清理使用相同规则。

0.1.65 本地修复包在 Windows / Python 3.13.9 / PyMuPDF 1.28.2 / requests 2.32.5 运行 70 项离线测试，无跳过；用合成 PDF 复现旧版预览 `worker_failed` / `Bad file descriptor`，修正后预览与模拟 OXR 的版面生成通过。进度 flush 测试改用有界线程读管道，避免 Windows select 仅支持 socket；Windows 信号处理测试以 `signal.raise_signal()` 检查 Python 处理器，不宣称验证外部强制结束的处理器执行。没有操控 Zotero、请求真实 OXR/模型、上传论文或验证原生中文 PDF/附件导入。

Windows JavaScript 验证对 Fluent 消息的 LF/CRLF 换行等价处理；仅原生 `/bin/sh` + `/bin/sleep` OpenCode 进程探针在 Windows 显式跳过，其他模型收集/取消模拟测试继续执行。0.1.65 本地修复包为 870 项通过、1 项跳过；JS 语法、静态检查与可复现 XPI 归档检查通过。

Python 文件同步依据见 [os.fsync](https://docs.python.org/3/library/os.html#os.fsync)，Windows 目录条目元数据限制见 [os.DirEntry.stat](https://docs.python.org/3/library/os.html#os.DirEntry.stat)。

## Markdown contract

所有分段拼接必须逐字还原输入，不能简单以空行拆断代码、公式或 HTML 表格。References / Bibliography / 参考文献标题下的条目整体保持原文；用户在确认前检查识别数量，缺少可识别标题时先修正。正文及引用块可以翻译，文内 `[1]` 等标记不变。

采用统一的正文片段协议，不保留旧长标记请求/响应适配器。每段词法分解为本地保护骨架与连续 ID（t0、t1…）正文片段。请求 source 只含 {id,text}，context 按原顺序只含正文 ID 或保护类别；不得包含保护原值。响应严格为 {translations:[{id,text}]}，翻译和校对使用相同格式，每段的全部片段一起请求，不按片段增加请求次数。系统指令提供完整示例；重试只追加固定格式反馈，不将供应商原始错误或本地资源反射到请求中。

验证响应类型、字段、片段数量、ID与顺序，拒绝缺失、重复、新增、乱序和空正文；再将正文插回本地原稿骨架，并重新词法校验，拒绝新增格式、链接或保护内容变化。即使模型不输出编号、换行和公式，也能准确保留它们；这不是猜补丢失的模型内容。Unicode空白（含NBSP、细空格、全角空格）在片段边缘及独立空白处留在本地，不能成为模型必须返回的空正文。内部词间空格仍属于可译正文。存盘译文加载时再次验证，不能因为曾经通过就信任本地检查点。单个非空片段可以仅含标点：中英语序会让同一句中公式等行内保护元素两侧的措辞移动，如“. The sampling of [公式] follows…”译为“。[公式]的采样遵循…”。不得以逐片段是否含字母/数字判断漏译；只做整段正文最低检查：原段正文含字母/数字时，整段译文正文不能全部变成标点/符号，保护公式内的字符不计入正文。空字符串、仅空白、缺失ID、结构变化仍拒绝，不填补空片段或猜造标点。系统指令要求保持ID、数量和顺序，只在同一句行内保护元素附近调整措辞，不跨段落/列表项/表格单元移动；独立校对结合整段核对意义。结构检查不能证明没有局部漏译或意义错置，最低检查不冒充语义保证。此校验修正不改变协议2、配置修订或默认提示词配置，已保存的新协议检查点/草稿继续复核使用。

源码最多 128 MiB UTF-8；单段待译正文片段合计最多 128000 UTF-16 单元，译文正文合计最多 256000 单元。每段最多4096个正文片段、16384个上下文项；结构元数据不冒充正文，{source,context}序列化外壳另限6×128000+128×16384+64单元。原始图片等资源不进入模型文本，但仍受源码上限约束。输入、响应及重载检查点都不能静默截断，超限由用户在确认页拆分。这是插件资源边界而非模型 token 限额，不自动合并已有分段、改变段 ID 或切换模型。URL 候选查找按字符段扫描，尾部空白从末尾扫描，避免长无空格正文或内部空白导致未锚定正则的二次回溯；保护语义不变。

全文翻译和独立校对请求均设置 max_tokens=131072、单请求超时 15 分钟；划线/摘要等其他请求仍使用原超时，取消不等待超时。JSON 响应外壳最多 6×256000+128×4096+64 UTF-16 单元，以容纳 Unicode 转义及片段元数据；解析后的全部 text 合计再次按译文上限校验。即使返回合法 JSON，只要 finish_reason=length 也拒绝该轮结果、暂停并保留既有检查点，不作为格式错误自动重试计费。更高预算不保证所有长块都能在时限内完成，自定义 DeepSeek 兼容地址或其他模型可能有更低限额。

容量选择参考 [DeepSeek 模型文档](https://api-docs.deepseek.com/quick_start/pricing) 的 deepseek-flash 1M 上下文及 384K 最大输出 tokens，以及 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion) 的 max_tokens 上限 393216；UTF-16 单元不等于 tokens，校对还同时携带原文和草稿，因此不直接把插件单段限制设为整个上下文容量。

保守支持常见 Markdown、HTML 表格及合并单元格；不支持的 HTML 保留源码，不解释为活动内容。裸 LaTeX 环境必须保留完整 begin/end 才交给 KaTeX，只有数学定界符本身可去除。

## Translation progress

翻译进度条独立于 PDF 解析时间轴。完成数只取通过翻译、校对、结构校验且已原子持久化的段落数；分母只计需翻译的段落，不计受保护的参考文献/代码等。百分比不按耗时或 token 数估算；进度未满时显示值不得因四舍五入提前到 100%。同时展示实际翻译中、校对中、保存中、待处理与失败段数，以及失败后的收尾状态。100% 仅表示全部待译段已通过并保存，PDF 生成/导入仍以独立状态显示；零待译段不显示虚假运行百分比，稿件改变时明确旧进度已失效、待重新确认。

各段乱序返回不改变最终正文顺序。工作队列与临时阶段只驻留内存；公开快照不暴露可变内部对象或所有段落草稿。阶段通知按 50 ms 合并，完成/失败/暂停即时发布，不重绘原文或覆盖未保存修正。恢复以持久检查点重新计算进度，不恢复虚构的在途状态。

## Unified page document and previews

确认窗口默认按左侧 PDF 当前页展示原文，不以整篇或整批结果冒充当前页，也不按空行、相似度或长度猜测页界。普通接口的 `outputs.json.pages[].page_num` 是零基页码，块的 `idx/type/content/format` 提供阅读顺序与内容。批量上传规则不变，不为逐页展示追加请求。

Python 只保留上述白名单字段及版面所需坐标，有界重建标题、公式、代码与其他块。缺少所需字段时整页不可用，不能只展示部分块并冒充完整页；完整空块列表可表示空页。原始逐页记录作为内容寻址的 `pages-<SHA-256>.json` 保存（128 MiB UTF-8 上限），绑定原 PDF 哈希、原始解析 Markdown 哈希及总页数；服务校验后才使用，不将所有页复制进每次状态快照。OXR 缓存修订保持 2，旧缓存不删除。

只有全部页具备完整记录时，新解析才建立统一编辑稿。每页原文按固定两个 LF 分隔组成完整原文，当前页、全文预览与翻译输入同源；允许与 OXR 原始 `outputs.markdown` 排版不同，不声称是中文 PDF 页码映射。原始全文仍保留在 `source.md` 和 `original-<hash>.md`，不可变识别页不被编辑覆盖。`document-<hash>.json` 保存页数组，绑定任务身份、PDF 摘要、原始逐页文件和解析 Markdown 摘要；文件和整稿哈希、页数及每页类型均须核验，JSON 与整稿各限 128 MiB UTF-8、最多 10000 页。

“编辑一段”只编辑当前页选中的顶层内容块，包括正文、公式、表格或图片；使用精确字符偏移及当前稿件版本，不按相似文本查找或替换。保存校验 Unicode、大小和结构，原子提交新版本后才刷新页稿；失败保留草稿，陈旧版本拒绝。未闭合 Markdown 可退化成整页源码块供修复，不能解释活动内容。“预览全文”只显示含已保存修改的完整原文，可返回当前页，不展示译文。未保存编辑在切页、切模式、发起操作或关闭前确认丢弃。

旧任务加载不自动转换。首次编辑需明确确认：用原始识别页重新组成统一稿（可能替代旧手改内容），先备份当前旧稿并归档检查点，成功才切换；归档通过 archivedSourceFile/archivedSourceHash 引用精确旧稿。缺页/损坏记录禁用编辑并提示明确确认后重新解析，不能猜测映射。旧批准稿与译文保留至重新确认；整稿哈希变化时禁止继续翻译、生成 PDF 或导出旧译文。重开先用已批准稿验证旧译文，再载入工作稿；统一稿损坏时报错并禁编辑，不把回退稿伪装成已恢复的新稿。

翻页、原始/版面切换时清除旧页内容，PDF 返回后复核窗口、请求序号及实际页码；失败不保留另一页。暂停、重解析、切模式、稿件版本变化与关闭使旧预览/图片回调失效。块选择保持原生文本拖选；图片成功后仅替换对应占位节点，不重绘正文或覆盖未保存编辑。

## Remote images

受控后端自动下载原文预览中的 PNG/JPEG/GIF/WebP。为兼容可更换的解析API及其对象存储，不固定入口/目标域名、目录或文件名形状；支持公网 HTTP(S)、编码路径、签名 query、协议相对及相对地址（初始相对地址按配置API目录解析），fragment不参与请求。允许公开IP地址；拒绝URL用户名/密码、控制字符、反斜杠、非HTTP(S)、本机/私网目标及SVG/活动HTML。HTTP不提供传输加密，此权限仅用于原文及译文中保留的图片资源，不扩展PDF上传或模型授权。

301/302/303/307/308跳转由图片模块逐跳处理，最多5跳，循环或无效Location立即拒绝；相对Location按当前请求地址解析。每跳重新验证地址，所有跳共用15秒超时与取消信号。Gecko专用通道在新目标连接前阻止自动重定向，只返回元数据；标准fetch manual的opaque redirect不能作为可读Location来源。通道连接前DNS预检，最多64个地址，通常需全部为公网。为兼容代理Fake-IP，非本机/内部名称的多标签域名解析结果可接受标准IPv4形式的198.18.0.0/15；请求始终保留原域名，不把解析地址写回URL或修改系统代理/DNS。此例外不适用于IP字面URL、本机/内部域名、其他私网/保留地址或映射IPv6形式的Fake-IP；混合记录中只要出现其他不允许地址仍拒绝，初始地址与每跳同样执行。DNS失败/空结果/取消不启动HTTP。该地址段本身不能证明代理存在，此兼容策略信任现有网络会按域名正确路由；预检不是DNS绑定或绝对SSRF沙箱，不承诺抵御DNS重绑定、特殊网段中的其他服务或代理重路由。

通道固定匿名GET、无referrer、禁缓存，不继承Cookie、认证头或交互式认证/证书弹窗，不借用会记录签名URL的Zotero HTTP辅助方法。最终仅接受200和未被底层自动跟随的精确请求URL，Content-Length预检及流累计均受限，原生读取前也限制字节，取消/迟到不得继续读取或启动下一跳。无扩展名图片按实际签名识别；允许标准图片MIME大小写/参数，以及空或通用binary MIME下通过签名和尺寸校验的图片，明确冲突的MIME拒绝。HTTP压缩传输长度不冒充解压后的图片长度，解压流仍受同一上限。

单图最多12 MiB、边长16384、像素40 Mi；任务缓存实例最多128张/64 MiB。图片经签名、MIME、尺寸校验后才缓存并交给DOM；跨realm字节不使用同realm instanceof判断。临时跳转及签名地址只存在于当前请求内存，不进入诊断/缓存；缓存始终使用初始规范化图片URL的哈希。

缓存位于任务自有 `images/<URL-SHA256>.json`，仅保存 schema、URL 哈希、内容哈希、MIME 和 data URI，不存原始 URL/认证头/密钥；原文 Markdown 本身仍保留原图片地址。每次磁盘读取重验内容摘要与图片，损坏记录报错，不信任原始路径。逐级拒绝软链接，单 JSON 17 MiB、目录最多 128 个记录，序列化总字节不超过 floor(64 MiB × 4/3)（含 base64 和 JSON 开销，保守保证关闭重开后累计图片仍不超过 64 MiB），写入串行且原子；释放服务与退出等待在途写入。取消可能留下已经校验的原子缓存，但不能发布迟到图片。失败保留原图片 Markdown 并允许重试，不自动循环重试或放宽地址。

预览/打印文档 CSP 不变：不允许直接远端或 file 图片。异步图片提交还经过渲染器单视图 64 MiB 及节点上限；网络缓存不改变原文、本地保护骨架或模型输入。图片缓存同时用于原文预览和中文PDF准备。打印前优先复用当前任务内存/磁盘缓存，未缓存图片通过相同后端下载；暂停/关闭/失败取消在途请求，迟到结果不能提交DOM或继续打印。Markdown文本导出仍不下载图片。

## State, storage and cancellation

本机任务身份包含文库 ID、原附件 key 和源 PDF SHA-256，根目录为 Zotero 数据目录的 `smart-paper-translator/fulltext/`。不复用摘要/术语缓存，因为同一父论文可能有多个内容不同的 PDF。

确认稿按内容哈希单独保存，状态原子提交；检查点签名包含地址、模型、提示词、固定中文目标与协议修订，不含密钥。当前 translationProtocol=2、配置 revision=2；按用户对未发布协议的破坏性更新授权，旧确认任务无该协议标识时保留原稿，但不发布或续用旧译文、草稿及完成进度，需重新确认后全部翻译，不重新上传/解析PDF。打开只读不写盘、不发请求；后续本地保存可覆盖失效进度，不承诺旧翻译检查点回退。不删除原PDF或既有附件，导入结果不确定仍拒绝重置。确认稿或配置变化需要再次确认，并重置当前译文检查点，不覆盖文库中已有中文附件。对已有确认稿重新解析还须另行明确确认：在发起转换前将旧状态归档为 `history-<状态内容哈希>.json`，保留其引用的内容寻址确认稿和逐页记录；只有新结果校验及状态原子保存成功、写后请求序号仍有效才发布新状态并清空旧翻译进度；保存期间取消须恢复并持久化旧检查点，不发布临时新稿。失败或取消保留旧确认稿和检查点。归档供恢复依据使用，不自动导入、删除已导入附件或回放请求；导入结果不确定时禁止重建。已保存的单块编辑在未确认翻译前也持久化；只有 textarea 中未保存的编辑可能在关闭时丢失，关闭前须警告。任务数据不加密、不自动参与 Zotero 同步，自动清理不删除用户文库或外部文件。

暂停/关闭使请求序号失效，取消模型请求并回收 Python；迟到结果不能推进任务或读取到密钥后才启动新请求。重新打开不自动续费。子进程不能确认退出时保留引用并阻止重新启动。Python 从用户指定的现成环境运行固定包内脚本，用独立 argv 和隔离模式，不用 shell、不自动下载依赖。候选发现不执行程序。未选择 Python、路径不是本机绝对路径、文件不存在或误选目录时，错误必须明确指出 Python 并引导到设置中的「论文全文翻译」选择环境及检测本地依赖；在写辅助脚本或启动进程之前拒绝，不自动选择替代环境。Python 允许虚拟环境解释器软链接。原 PDF 未下载、丢失或路径无效及 Markdown 导出路径无效应分别指出对应文件，不能与 Python 配置共用模糊的绝对路径提示。

翻译和校对的每次请求都复核当前原稿/模型配置仍与本轮确认一致；异步文件准备或读取密钥期间发生配置变化也不能启动后续请求。配置变化不按格式错误自动重试，已完成检查点仍按原签名保留，需明确重新确认才使用新配置。

并发结果的检查点写入严格串行，更新基于轮到写入时的最新已提交状态，原子保存成功且请求序号仍有效才发布完成；写入失败或取消尝试恢复上一已提交状态。暂停/关闭使排队提交与迟到模型结果失效，等待在途请求、保存和回滚全部结束后才允许重启，防止旧保存覆盖新任务。未保存成功的结果不计为完成，不允许生成/导出部分译文。失败草稿与错误有长度上限且必须绑定当前确认稿的未完成段；不因并发改变批准稿或翻译配置哈希。

保存附件前写入导入意图。尚未调用导入就取消时清除意图；已经调用但事务结果不确定时保留意图并阻止自动重复导入。导入已开始时即便窗口关闭也记录最终结果。中文附件由 Zotero API 复制到原论文下，语言切换复核本地映射中的文库、父条目和附件 key，调用原生 Reader 打开；原附件与批注不改动。已有完成任务的默认finish仍幂等；只有用户明确确认“重新生成中文 PDF”才复用现有译文重新输出并新增附件，不重译、不删除旧附件、不作旧版专用迁移。再次导入前，将旧chineseAttachmentID清空与新导入意图一起持久化；尚未调用导入时失败/取消恢复旧ID，已调用但结果不确定时保留意图和空ID以阻止重复导入/重置。成功后更新当前原附件的语言映射。界面确认后再次核对任务、原稿、配置和旧附件ID，陈旧或取消的确认不启动操作。

## Rendering and PDF output

OCR 和模型内容均视为不可信数据。只通过白名单 DOM 构建文本、表格及本地 KaTeX MathML，不使用 innerHTML。图片只接受有界且 MIME/签名/尺寸一致的 PNG/JPEG/GIF/WebP 内嵌资源，单图 12 MiB、总计 64 MiB；DOM 不直接加载远端图片和本地任意路径，原文预览只接受图片模块交付并再次校验的 data URI。渲染节点/嵌套深度均有限制。代码、脚本、表单、活动 HTML 和外部资源不获得特权。算法预格式块可在保留换行/缩进的同时渲染其中的数学片段：仅明确 `algorithm` / `pseudocode` 围栏，或紧邻编号算法标题且同时具备输入/输出标记、do/then 控制流和 end for/while/if 结束行，并无引号字符串或明确程序声明语法的无语言/text/缩进/简单 HTML 代码块。明确标为程序语言的代码、普通代码块及行内代码仍保持字面显示。算法中除数学定界符外的 HTML、图片、链接及反斜杠也保持纯文本；公式继续走本地 KaTeX 的不可信 MathML 管线，无法解析时保留源码。不修改翻译保护骨架；识别不明确时不强行渲染。

打印先在惰性文档生成白名单静态DOM，并收集渲染器实际识别的外部图片占位（Markdown或白名单HTML img），不通过扫描所有URL下载代码示例或普通链接。最多128种图片引用，同一引用合并请求并更新所有占位；逐个等待任务ImageCache返回经校验的data URI，再经过渲染器的签名/尺寸/单图及累计64MiB限制提交。内嵌图片同样验证。缺少缓存适配器、下载或校验失败时禁止生成和导入缺图PDF，不能用原链接文字冒充成功。图片准备全程可取消，复核属主Document及运行状态；全部准备成功后才挂载打印iframe，内容文档仍不获得网络权限。

惰性文档没有defaultView，XML parser由宿主提供，但渲染节点仍只创建/导入惰性文档。自有iframe挂载前设置mozframetype="content"与空sandbox，通过显式src="about:blank"导航建立无脚本/网络的打印内容文档。不能使用srcdoc：chrome内的content框架在Gecko中成为顶层内容上下文，顶层srcdoc不合法。只打印该自有内容上下文，不退回chrome顶层、放宽sandbox/父CSP、改用大正文data/Blob URL或延长超时。

监听在设置src/挂载前注册（capture与wantsUntrusted）；只接受可信load，originalTarget/target必须是当前contentDocument，且URI为about:blank、readyState为complete、框架仍连接当前属主、BrowsingContext为可打印的内容上下文。不能用同步可见的初始空白页、元素/子资源load或同URI而不同文档替代真实导航完成。接受后固定Document/BrowsingContext，后续异步准备和提交前复核；取消、失败与结束移除监听、计时器和frame，迟到事件不能重新启用打印。

真实导航完成后，以目标Document.importNode先将固定打印CSP meta单独追加到现有head，再导入其余固定头部节点/样式与白名单正文。动态meta必须在正文资源绑定前生效；不假设惰性文档的策略自动复制，也不解析HTML字符串、document.write或搬移特权活节点。继承父CSP并追加更严格的打印CSP：script/connect/object/frame均为none，图片仅data，样式仅固定内联。导入后仍须等待字体与全部图片解码，不能把之前空白文档的load当成图片就绪。

独立确认窗口的原生打印需要短生命周期nsIBrowserDOMWindow宿主。该适配只在本次原生打印期间挂到当前窗口，已有非空宿主不覆盖、不转发，其他窗口不改动。安装后记录读回的接口对象以兼容XPConnect包装；清理只在该对象仍由自己持有时恢复空值，不能清除他人替换的宿主。非空宿主也阻止同窗口并发接管。

打印使用独立 settings，不更改系统/Zotero 打印偏好；打印机名称固定为Mozilla Save to PDF，明确PDF/file输出。先设置printerName和页面参数，最后再置isInitializedFromPrinter/isInitializedFromPrefs，因为名称setter会清除初始化标志。等待字体与全部图片解码成功，写入每次唯一的自有临时 PDF。生成后检查 PDF 签名并用 Python 解析首页面，才替换最终 PDF。暂停/超时的迟到打印只可能残留唯一临时文件，不得覆盖已有成品或导入文库。若打印失败，已完成 Markdown 保留，用户可导出或重试，不能把无效/缺图 PDF 当作成功。打印阶段（加载文档、字体/图片、设置、原生打印、校验、提交）错误保留有界可读原因和可用nsresult，不采集额外正文或日志；非Error原生异常不应退化为无信息的“全文任务失败”。
