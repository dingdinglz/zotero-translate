## Responsibility

将论文的单个 PDF 附件转换为可检查的 Markdown，用户确认后逐段翻译与校对，保留中文 Markdown 并生成独立中文 PDF 附件。原始 PDF、既有批注及 Agents 会话不变。此模块不承担原版布局复刻、批注迁移或页码对齐。

用户流程与运行依赖已获批准；本文作为新增持久模块说明，尚待单独审阅。原生打印及实际导入的验证缺口见技术参考，不由自动测试或版本兼容声明推导成功。

## Boundary

任务核心负责确认门控、状态和检查点；Markdown 模块负责无损分段、保护和安全排版；本机桥负责附件身份、文件、Python 子进程和 Gecko 打印；窗口只绑定打开时的任务，不跟随 Reader 切换。Python 工具仅处理 PDF，拥有 OXR 分块/缓存和本地版面/页面渲染，不持有 DeepSeek 密钥。

Reader 入口从 tabID 精确复核附件，仅支持主窗口 PDF 标签页。全文翻译按钮与中英文原生下拉框作为同一工具组，使用与 Reader 按钮一致的 28px 高度并垂直居中，保留原生选择和键盘语义。没有普通父论文或文库不可写时拒绝，不能猜测另一附件或自动创建父条目。同一任务只保留一个可编辑确认窗口，替换必须先暂停并回收旧服务。

## Consent and network

打开窗口与读取检查点不联网。首次明确确认目标地址后，Python 才将 PDF 分块上传至配置的 OXR。默认地址为 Free OXR；只允许 HTTPS 或本机 HTTP，拒绝 URL 中的凭据、查询和片段，不跟随重定向。每块最多 20 页、9.5 MB；单页超限报错，不静默栅格化降质。缓存包含任务 ID、识别内容和版面数据；关闭本地进程不保证取消远端任务，重试提交也可能产生远端重复任务。

另一明确确认才允许向当前 DeepSeek 地址/模型发送待翻译段落，并授权全部通过后自动生成和保存中文附件。共用现有翻译服务配置及 Login Manager 密钥，但全文翻译/校对提示词独立、目标固定为简体中文。当前服务非 DeepSeek 时拒绝，不偷偷改供应商。

只有文本和保护占位符进入模型；本地保护元数据中的图片、代码、公式和引用不发送。每段串行执行翻译、独立模型校对、程序校验；结构错误最多三轮，鉴权/网络类错误不按格式错误重复计费。语义正确性不能由结构校验保证。

## Markdown contract

所有分段拼接必须逐字还原输入，不能简单以空行拆断代码、公式或 HTML 表格。References / Bibliography / 参考文献标题下的条目整体保持原文；用户在确认前检查识别数量，缺少可识别标题时先修正。正文及引用块可以翻译，文内 `[1]` 等标记不变。

确定性、碰撞检查的占位符保护公式、代码、图片、链接目的地、空白及 Markdown/HTML 结构。恢复拒绝缺失、重复、新增、乱序的占位符和骨架变化。存盘译文再次加载也重新验证，不能因为曾经通过就信任本地检查点。

源码最多 128 MiB UTF-8；单个待翻译段在保护后最多 16000 UTF-16 单元，不静默截断，超限由用户在确认页拆分。保守支持常见 Markdown、HTML 表格及合并单元格；不支持的 HTML 保留源码，不解释为活动内容。裸 LaTeX 环境必须保留完整 begin/end 才交给 KaTeX，只有数学定界符本身可去除。

## State, storage and cancellation

本机任务身份包含文库 ID、原附件 key 和源 PDF SHA-256，根目录为 Zotero 数据目录的 `smart-paper-translator/fulltext/`。不复用摘要/术语缓存，因为同一父论文可能有多个内容不同的 PDF。

确认稿按内容哈希单独保存，状态原子提交；检查点签名包含地址、模型、提示词和固定中文目标，不含密钥。确认稿或配置变化需要再次确认，并重置当前译文检查点，不覆盖文库中已有中文附件。未确认编辑不承诺持久化，关闭时警告可能丢失；已确认段落可恢复。任务数据不加密、不自动参与 Zotero 同步，自动清理不删除用户文库或外部文件。

暂停/关闭使请求序号失效，取消模型请求并回收 Python；迟到结果不能推进任务或读取到密钥后才启动新请求。重新打开不自动续费。子进程不能确认退出时保留引用并阻止重新启动。Python 从用户指定的现成环境运行固定包内脚本，用独立 argv 和隔离模式，不用 shell、不自动下载依赖。候选发现不执行程序。

保存附件前写入导入意图。尚未调用导入就取消时清除意图；已经调用但事务结果不确定时保留意图并阻止自动重复导入。导入已开始时即便窗口关闭也记录最终结果。中文附件由 Zotero API 复制到原论文下，语言切换复核本地映射中的文库、父条目和附件 key，调用原生 Reader 打开；原附件与批注不改动。

## Rendering and PDF output

OCR 和模型内容均视为不可信数据。只通过白名单 DOM 构建文本、表格及本地 KaTeX MathML，不使用 innerHTML。图片只接受有界且 MIME/签名/尺寸一致的 PNG/JPEG/GIF/WebP 内嵌资源，单图 12 MiB、总计 64 MiB；远端图片和本地任意路径不加载。渲染节点/嵌套深度均有限制。代码、脚本、表单、活动 HTML 和外部资源不获得特权。

打印先在惰性文档生成静态内容，再交给禁止脚本与网络的 sandbox iframe。惰性文档没有 defaultView，XML parser 由宿主提供，但节点仍只创建/导入惰性文档。Gecko chrome 宿主必须在自有 iframe 上接收内容域 load 事件（capture 与 wantsUntrusted），并确认精确的 about:srcdoc 文档；不能因缺事件而放宽沙箱。

打印使用独立 settings，不更改系统/Zotero 打印偏好；等待字体与全部图片解码成功，写入每次唯一的自有临时 PDF。生成后检查 PDF 签名并用 Python 解析首页面，才替换最终 PDF。暂停/超时的迟到打印只可能残留唯一临时文件，不得覆盖已有成品或导入文库。若打印失败，已完成 Markdown 保留，用户可导出或重试，不能把无效/缺图 PDF 当作成功。
